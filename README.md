# React + TypeScript + Vite + tRPC

Проект показывает связь React-клиента с существующим backend на tRPC. По нажатию кнопки клиент вызывает `logButton`, а сервер пишет сообщение в терминал.

## Требования
- Node.js 20.19+ или 22.12+
- npm

## Запуск
В терминале из корня проекта:

```bash
npm install
npm run dev
```

Открой адрес клиента, который Vite покажет в терминале (обычно http://127.0.0.1:5173). Не закрывай терминал: серверные логи появляются там же, в строках с префиксом `[КНОПКА]`.

## Проверка
1. Дождись сообщений `Сервер запущен: http://127.0.0.1:3000` и Vite `Local: http://127.0.0.1:5173`.
2. Открой клиент в браузере.
3. Нажми `Нажми меня`.
4. На странице появится подтверждение, а в терминале будет строка `[КНОПКА] ... Пользователь нажал кнопку`.

## Git и отправка Артёму
Создай пустой репозиторий на GitHub, затем выполни в папке проекта:

```bash
git init
git add .
git commit -m "Add React client connected to tRPC backend"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/ВАШ-РЕПОЗИТОРИЙ.git
git push -u origin main
```

Замени URL на адрес своего репозитория. После этого отправь Артёму ссылку на репозиторий.
